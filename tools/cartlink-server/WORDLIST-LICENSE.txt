eff_short_wordlist_1.txt
========================

The file eff_short_wordlist_1.txt in this folder is "EFF's Short Wordlist #1"
by the Electronic Frontier Foundation, unchanged:

    https://www.eff.org/files/2016/09/08/eff_short_wordlist_1.txt
    (described at https://www.eff.org/dice)

new friend's password. If the file is missing or changed (its SHA-256 is not the
one above), cartlink-users uses 24 random base32 characters instead.
